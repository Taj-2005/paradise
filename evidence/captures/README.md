# Packet captures

Generated by `./scripts/capture.sh {dns|tcp|tls|full}`. **Gitignored** — the
form asks for your *description*, not the file, and unfiltered captures get
large fast.

Keep them locally so you can open one during the demo (final demonstration
step 6 expects a saved capture on screen).

| Mode | Capture filter | Wireshark display filter |
|---|---|---|
| `dns` | `udp port 53` | `dns` |
| `tcp` | `tcp port 443` | `tcp.flags.syn==1` |
| `tls` | `tcp port 443` | `tls` |
| `full` | both | `dns \|\| tcp.flags.syn==1 \|\| tls` |

Capture-time filtering is deliberate: an unfiltered capture on shared Wi-Fi is
mostly other people's traffic, and hunting for your three interesting packets
wastes demo time.
