# Evidence

Every file here maps to one field on the Phase 1 submission form. The spec
asks that an evaluator can find any piece of evidence within 30 seconds — that
is what this index is for.

Generate most of it with:

```bash
make evidence        # run from a CLIENT machine, not Mac 2
```

## Form field → file

| Field | What it asks for | File | Generated by |
|---|---|---|---|
| A1 | Machine IPs, roles, interfaces | `A-lan-dns/A1-ips.txt` | `make evidence` |
| A2 | dnsmasq config lines | `../infra/mac1-dns/dnsmasq.conf` | `make render` |
| A3 | `dig` from a **client** | `A-lan-dns/A3-dig-client.txt` | `make evidence` |
| A4 | `dig @8.8.8.8` → NXDOMAIN | `A-lan-dns/A4-dig-8888.txt` | `make evidence` |
| A5 | Ping between all pairs | `A-lan-dns/A5-ping-matrix.txt` | `make evidence` on each Mac |
| B1 | `curl -v` over HTTPS, **no `-k`** | `B-https-lb/B1-curl-verbose.txt` | `make evidence` |
| B2 | 6 responses showing `X-Backend` | `B-https-lb/B2-lb-6x.txt` | `make evidence` |
| B3 | nginx upstream + server block | `B-https-lb/B3-nginx.conf` | `make evidence` |

| C2 | Wireshark TCP handshake | `C-wireshark/C2-tcp.md` | **you**, after `./scripts/capture.sh tcp` |
| C3 | Wireshark TLS handshake | `C-wireshark/C3-tls.md` | **you**, after `./scripts/capture.sh tls` |

## Rules that cost marks

- **No `-k`** in anything under `B-https-lb/`. It scores zero for HTTPS.
- **A3 must come from a client** — Mac 1, 3 or 4, never Mac 2.
  `collect-evidence.sh` refuses to run on the edge for this reason.
- **Domain names, never IPs**, in every URL.
- **C1–C3 need specifics.** "We saw packets" scores 0–1. Name the source and
  destination IPs, the ports, the packet types, and say what each proves.
- **Paste real output.** Never describe or summarise it.

## Captures

`captures/*.pcapng` are gitignored — they are large and the form does not ask
for the file, only your description. Keep them locally for the demo.
